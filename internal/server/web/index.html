Install jit-cli first. From a checkout of this repository, build it into your local executable path:

mkdir -p "$HOME/.local/bin" && go build -o "$HOME/.local/bin/jit-cli" ./cmd/jit-cli

Run that from the repository root, and make sure $HOME/.local/bin is on your PATH.

ONE-TIME TARGET SETUP

Trust the CA on your server

BEFORE FIRST LOGIN
  1. Download the CA public key. Only this public key belongs on target servers; never copy the CA private key.
  2. Copy it to each target server as /etc/ssh/jit_ca.pub, then set ownership and permissions: sudo install -o root -g root -m 0644 jit_ca.pub /etc/ssh/jit_ca.pub
  3. Add TrustedUserCAKeys /etc/ssh/jit_ca.pub to /etc/ssh/sshd_config. Validate with sudo sshd -t, then reload SSH (often sudo systemctl reload sshd; on Debian/Ubuntu the service may be named ssh).
  4. Request access with the form above and run the SSH command printed by the CLI. The target account must already exist and match the requested username.

Operator note: protect and back up the CA private key on the issuer’s persistent disk. Anyone who can request certificates can currently ask for any target account; this service does not yet authenticate or authorize requesters. Do not expose it publicly for production use without adding access controls.
